Description
-----------

TwitchRequestBase provides common HTTP request functionality for all API category classes. It handles the HTTP client connection and provides helper methods for making GET, POST, PATCH, PUT, and DELETE requests. This class is not used directly; instead, use the category-specific classes like :ref:`TwitchUsersRequests<class_TwitchUsersRequests>`, :ref:`TwitchStreamsRequests<class_TwitchStreamsRequests>`, etc.

Description

**JustAMCPPromptBlaziumWorkflow** backs the high-value JustAMCP workflow prompts for project intake, scene building, runtime testing, Autowork repair, and diagnostics triage. The prompts embed relevant ``blazium://`` resources and guide MCP clients through deterministic tool sequences.

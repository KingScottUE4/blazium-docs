=======================

Handles Kick API requests related to livestreams.

.. rst-class:: classref-introduction-group

Description
-----------

KickLivestreamsRequests provides methods for retrieving livestream information from the Kick API.

Access this handler through :ref:`KickAPI.get_livestreams()<class_KickAPI_method_get_livestreams>`.

|void| **get_livestreams**\ (\ params\: :ref:`Dictionary<class_Dictionary>` = {}\ ) :ref:`🔗<class_KickLivestreamsRequests_method_get_livestreams>`

Retrieves livestream information. The ``params`` dictionary can include:

- ``broadcaster_user_id``: Array of broadcaster user IDs (up to 50)

- ``slug``: Array of channel slugs (up to 50)

You cannot mix ``broadcaster_user_id`` and ``slug`` parameters.

Results are returned via the :ref:`KickAPI.request_completed<class_KickAPI_signal_request_completed>` signal with signal_name ``"livestreams_received"``.

::

    KickAPI.get_livestreams().get_livestreams({"slug": ["streamer123"]})

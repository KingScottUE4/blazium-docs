DSVReader
=========

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Streaming delimiter-separated value reader.

.. rst-class:: classref-introduction-group

Description
-----------

DSVReader reads CSV, TSV, PSV, and other single-character delimiter-separated files one row at a time. It uses the same parser options as :ref:`DSVImporter<class_DSVImporter>` without loading the full file into memory.

CSVAsyncTask
============

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Asynchronous CSV and DSV load/save task.

.. rst-class:: classref-introduction-group

Description
-----------

CSVAsyncTask runs CSV or DSV load/save work on a background thread. Use the static constructors to configure a task, call :ref:`start()<class_CSVAsyncTask_method_start>`, then poll state or wait with :ref:`wait_to_finish()<class_CSVAsyncTask_method_wait_to_finish>`. Load tasks expose rows with :ref:`get_rows()<class_CSVAsyncTask_method_get_rows>` and :ref:`get_table()<class_CSVAsyncTask_method_get_table>`.

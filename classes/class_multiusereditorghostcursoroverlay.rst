MultiuserEditorGhostCursorOverlay
=================================

**Inherits:** :ref:`Control<class_Control>` **<** :ref:`CanvasItem<class_CanvasItem>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Draws remote peer cursors over the active script editor.

.. rst-class:: classref-introduction-group

Description
-----------

**MultiuserEditorGhostCursorOverlay** renders transient cursor markers for remote peers in the active :ref:`CodeEdit<class_CodeEdit>`. It uses editor-derived line and column geometry so cursor markers follow wrapping, scrolling, and font metrics, and it removes stale cursor entries when peers stop broadcasting cursor updates.

The overlay is managed by :ref:`MultiuserEditorPlugin<class_MultiuserEditorPlugin>` and is enabled by the ``blazium/multiuser_editor/show_remote_cursors`` editor setting.

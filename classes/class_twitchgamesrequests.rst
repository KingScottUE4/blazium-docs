TwitchGamesRequests
===================

**Inherits:** :ref:`TwitchRequestBase<class_TwitchRequestBase>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Twitch Games API for game information and top games.

.. rst-class:: classref-introduction-group

Description
-----------

TwitchGamesRequests provides methods for retrieving game information and discovering top games by viewer count. No special OAuth scopes required. Access through :ref:`TwitchAPI.get_games()<class_TwitchAPI_method_get_games>`.

|void| **get_games**\ (\ params\: :ref:`Dictionary<class_Dictionary>`\ ) :ref:`🔗<class_TwitchGamesRequests_method_get_games>`

Gets information about specified games. ``params`` must include id, name, or igdb_id. Results are returned via the :ref:`TwitchAPI.request_completed<class_TwitchAPI_signal_request_completed>` signal with signal_name "games_received".

\ **Response includes:** Array of games with id, name, box_art_url (template with {width}x{height}), igdb_id.

::

    var params = {"name": ["Just Chatting", "Minecraft"]}
    TwitchAPI.get_games().get_games(params)
    # Response: {"data": [{"id": "509658", "name": "Just Chatting", "box_art_url": "https://static-cdn.jtvnw.net/ttv-boxart/509658-{width}x{height}.jpg", "igdb_id": ""}]}

|void| **get_top_games**\ (\ params\: :ref:`Dictionary<class_Dictionary>` = {}\ ) :ref:`🔗<class_TwitchGamesRequests_method_get_top_games>`

Gets games sorted by number of current viewers on Twitch. Optional ``params`` can include first, before, and after for pagination. Results are returned via the :ref:`TwitchAPI.request_completed<class_TwitchAPI_signal_request_completed>` signal with signal_name "top_games_received".

\ **Response includes:** Array of games with id, name, box_art_url, igdb_id.

::

    TwitchAPI.get_games().get_top_games({"first": 10})
    # Response: {"data": [{"id": "509658", "name": "Just Chatting", "box_art_url": "https://static-cdn.jtvnw.net/ttv-boxart/509658-{width}x{height}.jpg"}]}

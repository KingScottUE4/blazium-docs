Fluent configuration object for defining stub behavior.

.. rst-class:: classref-introduction-group

Description
-----------

The AutoworkStubParams class provides a fluent API for defining conditional stub behavior in tests.



It is used by :ref:`AutoworkStubber<class_AutoworkStubber>` to describe how a method should behave when called, including return values, argument matching, or whether the original method should be executed.

Test base class for the built-in unit testing framework.

.. rst-class:: classref-introduction-group

Description
-----------

The AutoworkTest class is the base class for defining unit tests in the Autowork framework.



Tests are typically implemented by extending this class and defining test methods that contain assertions.

The framework automatically discovers and executes these methods based on naming conventions and configuration rules provided by :ref:`AutoworkCollector<class_AutoworkCollector>` and :ref:`AutoworkConfig<class_AutoworkConfig>`.

:ref:`Signal<class_Signal>` **wait_for_signal**\ (\ signal\: :ref:`Signal<class_Signal>`, max_wait\: :ref:`float<class_float>`, message\: :ref:`String<class_String>` = ""\ ) :ref:`🔗<class_AutoworkTest_method_wait_for_signal>`

Will wait for ``signal`` emission for a ``max_wait`` amount of seconds.

This returns :ref:`timeout<class_AutoworkTest_signal_timeout>`, the return value will be true if the signal was emitted, false if ``max_wait`` was reached.

::

    var success = await wait_for_signal(player.respawned, 2, "Player should respawn within 2 second")
    if success:
        pass_test("Player repawned within 2 seconds")
    else:
        fail_test("Player respawn fail")

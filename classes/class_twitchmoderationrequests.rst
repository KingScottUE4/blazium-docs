TwitchModerationRequests
========================

**Inherits:** :ref:`TwitchRequestBase<class_TwitchRequestBase>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Twitch Moderation API for bans, timeouts, AutoMod, and moderator management.

.. rst-class:: classref-introduction-group

Description
-----------

TwitchModerationRequests provides comprehensive moderation tools including bans, timeouts, AutoMod management, blocked terms, moderator and VIP management, and Shield Mode. Requires various moderation-related OAuth scopes. Access through :ref:`TwitchAPI.get_moderation()<class_TwitchAPI_method_get_moderation>`.

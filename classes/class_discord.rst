Discord
=======

**Inherits:** :ref:`Object<class_Object>`

Discord Social SDK integration for RPC rich presence, OAuth, invites, and relationships.

.. rst-class:: classref-introduction-group

Description
-----------

The Discord singleton dynamically loads the Discord Partner SDK library at runtime. Use :ref:`initialize_presence_only()<class_Discord_method_initialize_presence_only>` for auth-less RPC rich presence, or :ref:`initialize()<class_Discord_method_initialize>` for the full OAuth social layer (friends, invites, server auth).

Pump :ref:`run_callbacks()<class_Discord_method_run_callbacks>` each frame (or rely on the engine frame hook) while the client is active.

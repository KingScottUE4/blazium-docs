CSVIndex
========

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Lookup index for CSV table rows.

.. rst-class:: classref-introduction-group

Description
-----------

CSVIndex stores a column-based lookup table built by :ref:`CSVTable.build_index()<class_CSVTable_method_build_index>`. It supports fast single-row and multi-row lookups and can report duplicate keys when built in unique mode.

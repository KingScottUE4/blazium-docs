KickChatRequests
================

**Inherits:** :ref:`KickRequestBase<class_KickRequestBase>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Handles Kick API requests related to chat.

.. rst-class:: classref-introduction-group

Description
-----------

KickChatRequests provides methods for sending chat messages to Kick channels.

Access this handler through :ref:`KickAPI.get_chat()<class_KickAPI_method_get_chat>`.

|void| **send_message**\ (\ content\: :ref:`String<class_String>`, type\: :ref:`String<class_String>`, broadcaster_user_id\: :ref:`int<class_int>` = 0, reply_to_message_id\: :ref:`String<class_String>` = ""\ ) :ref:`🔗<class_KickChatRequests_method_send_message>`

Sends a chat message to a channel. The ``content`` must be 500 characters or less.

The ``type`` must be either ``"user"`` or ``"bot"``.

When sending as a user, ``broadcaster_user_id`` is required.

When sending as a bot, the message is sent to the channel attached to your token.

Optionally provide ``reply_to_message_id`` to reply to a specific message.

Results are returned via the :ref:`KickAPI.request_completed<class_KickAPI_signal_request_completed>` signal with signal_name ``"chat_message_sent"``.

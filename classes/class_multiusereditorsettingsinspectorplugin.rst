MultiuserEditorSettingsInspectorPlugin
======================================

**Inherits:** :ref:`EditorInspectorPlugin<class_EditorInspectorPlugin>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Inspector integration for Multiuser Editor settings controls.

.. rst-class:: classref-introduction-group

Description
-----------

**MultiuserEditorSettingsInspectorPlugin** inserts the Multiuser Editor connection controls into the editor settings inspector under the Blazium settings group. It allows users to manage the same host, join, and stop workflow from the module settings page.

This class is an editor-only helper owned by :ref:`MultiuserEditorPlugin<class_MultiuserEditorPlugin>`.

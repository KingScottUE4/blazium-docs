CSVWriter
=========

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Streaming CSV writer with Variant stringification.

.. rst-class:: classref-introduction-group

Description
-----------

CSVWriter wraps :ref:`DSVWriter<class_DSVWriter>` and converts Variants with :ref:`CSVExporter.stringify()<class_CSVExporter_method_stringify>` while writing rows incrementally.

CSV
===

**Inherits:** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Resource containing delimiter-separated values parsed as dictionaries.

.. rst-class:: classref-introduction-group

Description
-----------

CSV stores rows parsed from CSV, TSV, PSV, or other delimiter-separated text. When :ref:`headers<class_CSV_property_headers>` is enabled, the first row is used as dictionary keys. Otherwise rows are stored with numeric column indexes.

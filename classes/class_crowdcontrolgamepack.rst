CrowdControlGamePack
====================

**Inherits:** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

A collection of effects, parameters, and metadata defining a CrowdControl session.

.. rst-class:: classref-introduction-group

Description
-----------

**CrowdControlGamePack** encapsulates all the :ref:`CrowdControlEffect<class_CrowdControlEffect>`\ s available in your game. It also stores metadata through :ref:`CrowdControlGamePackMeta<class_CrowdControlGamePackMeta>`. This pack can be exported to JSON for use in the CrowdControl Developer Portal.

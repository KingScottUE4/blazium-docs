TwitchHTTPClient
================

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Low-level HTTP client for Twitch API with rate limiting and request queuing.

.. rst-class:: classref-introduction-group

Description
-----------

TwitchHTTPClient handles HTTP communication with the Twitch API, including automatic rate limit tracking, request queuing, and retry logic. This class is used internally by :ref:`TwitchAPI<class_TwitchAPI>` and typically does not need to be accessed directly.

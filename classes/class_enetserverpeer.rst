ENetServerPeer
==============

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Represents a connected peer on the server side.

.. rst-class:: classref-introduction-group

Description
-----------

ENetServerPeer represents a client connection to an :ref:`ENetServer<class_ENetServer>`. It provides methods to send packets to the specific peer, disconnect them, and manage authentication state.

Each peer goes through a connection lifecycle: connecting → prelogin (if authentication is enabled) → authenticated → disconnecting.

.. _class_ENetServerPeer_method_authenticate:

.. rst-class:: classref-method

|void| **authenticate**\ (\ ) :ref:`🔗<class_ENetServerPeer_method_authenticate>`

Marks the peer as authenticated and moves them to the :ref:`STATE_AUTHENTICATED<class_ENetServerPeer_constant_STATE_AUTHENTICATED>` state. Can only be called when the peer is in :ref:`STATE_PRELOGIN<class_ENetServerPeer_constant_STATE_PRELOGIN>` state.

::

    func _on_peer_prelogin(peer: ENetServerPeer, login_data: Dictionary):
        if login_data.get("password") == "secret":
            peer.authenticate()
        else:
            peer.reject("Wrong password")

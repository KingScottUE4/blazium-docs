ResourceImporterCSV
===================

**Inherits:** :ref:`ResourceImporter<class_ResourceImporter>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Imports CSV, TSV, and PSV files as CSV resources.

.. rst-class:: classref-introduction-group

Description
-----------

ResourceImporterCSV imports delimiter-separated source files into :ref:`CSV<class_CSV>` resources for use in projects. It supports comma, semicolon, tab, and pipe delimiters, optional headers, parser options, and custom null and boolean mappings.

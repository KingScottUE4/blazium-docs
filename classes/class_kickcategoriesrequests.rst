KickCategoriesRequests
======================

**Inherits:** :ref:`KickRequestBase<class_KickRequestBase>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Handles Kick API requests related to categories.

.. rst-class:: classref-introduction-group

Description
-----------

KickCategoriesRequests provides methods for searching categories and retrieving category information from the Kick API.

Access this handler through :ref:`KickAPI.get_categories()<class_KickAPI_method_get_categories>`.

    func _on_request_completed(signal_name: String, response_code: int, data: Dictionary):
        if signal_name == "categories_received":
            # Output from search:
            # {
            #   "data": [
            #     {
            #       "id": 123,
            #       "name": "Gaming",
            #       "thumbnail": "https://..."
            #     },
            #     ...
            #   ],
            #   "message": "success"
            # }
            for category in data["data"]:
                print("Category: ", category["name"], " ID: ", category["id"])
    
        elif signal_name == "category_received":
            # Output from get_category:

            #     "id": 42,
            #     "name": "Just Chatting",
            #     "thumbnail": "https://..."
            #   },
            #   "message": "success"
            # }
            print("Category: ", data["data"]["name"])

|void| **get_categories**\ (\ search_query\: :ref:`String<class_String>`, page\: :ref:`int<class_int>` = 1\ ) :ref:`🔗<class_KickCategoriesRequests_method_get_categories>`

Searches for categories on Kick based on ``search_query``. Returns up to 100 results per page.

Results are returned via the :ref:`KickAPI.request_completed<class_KickAPI_signal_request_completed>` signal with signal_name ``"categories_received"``.

CSVReader
=========

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Streaming CSV reader with Variant conversion.

.. rst-class:: classref-introduction-group

Description
-----------

CSVReader wraps :ref:`DSVReader<class_DSVReader>` and converts each streamed field with :ref:`CSVImporter.parse_record()<class_CSVImporter_method_parse_record>`. It can return each row as an :ref:`Array<class_Array>` or, when headers are enabled, as a :ref:`Dictionary<class_Dictionary>` keyed by the first accepted row.

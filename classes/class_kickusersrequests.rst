KickUsersRequests
=================

**Inherits:** :ref:`KickRequestBase<class_KickRequestBase>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Handles Kick API requests related to users.

.. rst-class:: classref-introduction-group

Description
-----------

KickUsersRequests provides methods for retrieving user information from the Kick API.

Access this handler through :ref:`KickAPI.get_users()<class_KickAPI_method_get_users>`.

|void| **get_users**\ (\ params\: :ref:`Dictionary<class_Dictionary>` = {}\ ) :ref:`🔗<class_KickUsersRequests_method_get_users>`

Retrieves user information. The ``params`` dictionary can include:

- ``user_id``: Array of user IDs (up to 50)

- ``username``: Array of usernames (up to 50, max 25 chars each)

If no parameters are provided, returns information for the authenticated user.

You cannot mix ``user_id`` and ``username`` parameters.

Results are returned via the :ref:`KickAPI.request_completed<class_KickAPI_signal_request_completed>` signal with signal_name ``"users_received"``.

::

    KickAPI.get_users().get_users({"username": ["streamer123"]})

Steam
=====

**Inherits:** :ref:`Object<class_Object>`

Steamworks integration for Web API session ticket generation and backend authentication.

.. rst-class:: classref-introduction-group

Description
-----------

The Steam singleton dynamically loads the Steam API library at runtime. If the library is not found, all methods fail gracefully without crashing.

Use :ref:`request_web_api_ticket()<class_Steam_method_request_web_api_ticket>` to obtain a ticket for ``ISteamUserAuth/AuthenticateUserTicket``, then :ref:`authenticate_with_server()<class_Steam_method_authenticate_with_server>` to exchange it for a JWT from your backend.

Settings panel UI for Multiuser Editor connection controls.

.. rst-class:: classref-introduction-group

Description
-----------

**MultiuserEditorSettingsUI** is the embedded editor settings panel used by the Multiuser Editor module. It presents host, port, join, and stop controls alongside connection status text, allowing users to configure and control collaborative editor sessions from the Blazium editor settings page.

The panel is editor-only and delegates session operations to :ref:`MultiuserEditorPlugin<class_MultiuserEditorPlugin>`.

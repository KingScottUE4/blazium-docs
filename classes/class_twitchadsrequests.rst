TwitchAdsRequests
=================

**Inherits:** :ref:`TwitchRequestBase<class_TwitchRequestBase>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Twitch Ads API for managing commercials and ad schedules.

.. rst-class:: classref-introduction-group

Description
-----------

TwitchAdsRequests provides methods for starting commercials, getting ad schedules, and managing ad breaks on Twitch channels. Requires appropriate OAuth scopes (channel:edit:commercial for starting commercials). Access through :ref:`TwitchAPI.get_ads()<class_TwitchAPI_method_get_ads>`.

|void| **get_ad_schedule**\ (\ broadcaster_id\: :ref:`String<class_String>`\ ) :ref:`🔗<class_TwitchAdsRequests_method_get_ad_schedule>`

Gets the broadcaster's ad schedule information including snooze count, next ad time, and preroll-free time. Results are returned via the :ref:`TwitchAPI.request_completed<class_TwitchAPI_signal_request_completed>` signal with signal_name "ad_schedule_received".

\ **Response includes:** snooze_count, snooze_refresh_at, next_ad_at, duration, last_ad_at, preroll_free_time.

::

    TwitchAPI.get_ads().get_ad_schedule("broadcaster_id")
    # Response: {"data": [{"snooze_count": 1, "snooze_refresh_at": "2025-10-16T12:00:00Z", "next_ad_at": "2025-10-16T13:00:00Z", "duration": 90, "last_ad_at": "2025-10-16T11:00:00Z", "preroll_free_time": 300}]}

|void| **start_commercial**\ (\ broadcaster_id\: :ref:`String<class_String>`, length\: :ref:`int<class_int>`\ ) :ref:`🔗<class_TwitchAdsRequests_method_start_commercial>`

Starts a commercial break on the broadcaster's channel. ``length`` must be 30, 60, 90, 120, 150, or 180 seconds. Requires channel:edit:commercial scope. Results are returned via the :ref:`TwitchAPI.request_completed<class_TwitchAPI_signal_request_completed>` signal with signal_name "commercial_started".

\ **Response includes:** length (commercial duration), message (status message), retry_after (seconds until next commercial can be run).

::

    TwitchAPI.get_ads().start_commercial("broadcaster_id", 30)
    # Response: {"data": [{"length": 30, "message": "Commercial started", "retry_after": 480}]}

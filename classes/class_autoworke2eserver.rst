AutoworkE2EServer
=================

**Inherits:** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Internal WebSocket orchestration server for the Autowork framework.

.. rst-class:: classref-introduction-group

Description
-----------

An internal engine singleton deployed globally when the application is launched with E2E capabilities. It binds directly to the active :ref:`SceneTree<class_SceneTree>` and opens a strictly formatted WebSocket server, listening defensively for HMAC-authenticated UI orchestration and node querying payloads from web runners like Playwright and Jest.

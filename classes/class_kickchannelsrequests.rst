====================

Handles Kick API requests related to channels.

Description
-----------

KickChannelsRequests provides methods for retrieving and updating channel information from the Kick API.

Access this handler through :ref:`KickAPI.get_channels()<class_KickAPI_method_get_channels>`.

|void| **get_channels**\ (\ params\: :ref:`Dictionary<class_Dictionary>` = {}\ ) :ref:`🔗<class_KickChannelsRequests_method_get_channels>`

Retrieves channel information. The ``params`` dictionary can include:

- ``broadcaster_user_id``: Array of broadcaster user IDs (up to 50)

- ``slug``: Array of channel slugs (up to 50)

If no parameters are provided, returns information for the authenticated user.

Results are returned via the :ref:`KickAPI.request_completed<class_KickAPI_signal_request_completed>` signal with signal_name ``"channels_received"``.

::

    KickAPI.get_channels().get_channels({"slug": ["channelname"]})

|void| **update_channel**\ (\ data\: :ref:`Dictionary<class_Dictionary>`\ ) :ref:`🔗<class_KickChannelsRequests_method_update_channel>`

Updates livestream metadata for the authenticated user's channel. The ``data`` dictionary can include:

- ``stream_title``: New stream title

- ``category_id``: Category ID

- ``custom_tags``: Array of custom tags

At least one field must be provided.

Results are returned via the :ref:`KickAPI.request_completed<class_KickAPI_signal_request_completed>` signal with signal_name ``"channel_updated"``.

TwitchChannelPointsRequests
===========================

**Inherits:** :ref:`TwitchRequestBase<class_TwitchRequestBase>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Twitch Channel Points API for managing custom rewards and redemptions.

.. rst-class:: classref-introduction-group

Description
-----------

TwitchChannelPointsRequests provides methods for creating, updating, and deleting custom Channel Points rewards, as well as managing redemptions. Requires channel:manage:redemptions or channel:read:redemptions OAuth scopes. Access through :ref:`TwitchAPI.get_channel_points()<class_TwitchAPI_method_get_channel_points>`.

.. _class_TwitchChannelPointsRequests_method_create_custom_rewards:

|void| **create_custom_rewards**\ (\ broadcaster_id\: :ref:`String<class_String>`, reward_data\: :ref:`Dictionary<class_Dictionary>`\ ) :ref:`🔗<class_TwitchChannelPointsRequests_method_create_custom_rewards>`

Creates a custom Channel Points reward. ``reward_data`` must include title and cost, and can include prompt, is_enabled, background_color, and various limit settings. Results are returned via the :ref:`TwitchAPI.request_completed<class_TwitchAPI_signal_request_completed>` signal with signal_name "custom_reward_created".

\ **Response includes:** broadcaster_id/login/name, id, title, prompt, cost, image, default_image, background_color, is_enabled, is_user_input_required, max_per_stream_setting, max_per_user_per_stream_setting, global_cooldown_setting, is_paused, is_in_stock, should_redemptions_skip_request_queue, redemptions_redeemed_current_stream, cooldown_expires_at.

::

    var reward = {"title": "Highlight My Message", "cost": 500, "prompt": "Your message will be highlighted"}
    TwitchAPI.get_channel_points().create_custom_rewards("broadcaster_id", reward)
    # Response: {"data": [{"id": "reward123", "title": "Highlight My Message", "cost": 500, "is_enabled": true, ...}]}

.. _class_TwitchChannelPointsRequests_method_get_custom_reward_redemption:

.. rst-class:: classref-method

|void| **get_custom_reward_redemption**\ (\ broadcaster_id\: :ref:`String<class_String>`, reward_id\: :ref:`String<class_String>`, params\: :ref:`Dictionary<class_Dictionary>` = {}\ ) :ref:`🔗<class_TwitchChannelPointsRequests_method_get_custom_reward_redemption>`

Gets redemptions for a specific custom reward. Optional ``params`` can include id, status, sort, and first. Results are returned via the :ref:`TwitchAPI.request_completed<class_TwitchAPI_signal_request_completed>` signal with signal_name "custom_reward_redemption_received".

\ **Response includes:** Array of redemptions with broadcaster_id/login/name, id, user_id/login/name, user_input, status (UNFULFILLED/FULFILLED/CANCELED), redeemed_at, reward (full reward object).

::

    TwitchAPI.get_channel_points().get_custom_reward_redemption("broadcaster_id", "reward123", {"status": "UNFULFILLED"})
    # Response: {"data": [{"id": "redemption456", "user_id": "789", "user_name": "Viewer1", "status": "UNFULFILLED", "redeemed_at": "2025-10-16T12:00:00Z", ...}]}
